# client/

Aquí va el cliente MU Online Season 6 Episode 3 (ENG) y el
`MUnique.OpenMU.ClientLauncher`.

El contenido de esta carpeta está excluido de git (ver `.gitignore`): el cliente,
sus modelos y sus texturas son propiedad de Webzen y no deben publicarse.

Para probar en local, conectar el launcher a `127.127.127.127`, puerto `44405`.
No usar `127.0.0.1`: el cliente lo bloquea.
